# Changelog

## v0.1.0 - Unreleased

Initial public launch candidate.

- One-command deploy flow for AI-generated personal apps.
- Hetzner cloud setup for a user-owned cax11 VPS.
- Tailscale Serve integration for private app access.
- Embedded local dashboard and REST API.
- App lifecycle commands: install, list, start, stop, update, remove.
- Dashboard "Rebuild" button to redeploy locally-installed apps after editing their source.
- Docker Compose v1/v2 fallback.
- Release installer with repository, version, and install URL overrides.
- Example apps, proof bundle, and Paradigm demo notes.
